# App Store プレビュー / スクリーンショット構成メモ

最終更新: 2026-05-28

## 方針

- 写真が見える画面を必ず前半に入れる
- アプリの流れが一目で伝わる順番にする
- `ごほうびたまご` は後半で見せて、続ける楽しみを伝える

## スクリーンショット案

1. チュートリアル 1 枚目
   - 訴求: `写真3枚で、その日の思い出を残せる`
   - ねらい: 最初の 1 枚で「写真日記アプリ」だと伝える
2. チュートリアル 3 枚目
   - 訴求: `月の思い出を、1枚のアルバムに`
   - ねらい: このアプリ独自のアルバム機能を見せる
3. 実際の日記一覧または日記詳細
   - 訴求: `あとから見返しやすい`
   - ねらい: 実際の写真入りデータを見せる
4. アルバム完成版プレビュー
   - 訴求: `完成版をスクショして残せる`
   - ねらい: 出力イメージを具体的に見せる
5. チュートリアル 4 枚目
   - 訴求: `ごほうびたまごが育って、アルバムがもっと楽しくなる`
   - ねらい: 継続する楽しみを補足する

## App Preview 動画の流れ

1. Welcome かチュートリアル 1 枚目から開始
2. 写真つき日記を保存する流れを見せる
3. 日記一覧で振り返る
4. アルバムを完成させる
5. ごほうびたまごと、アルバムで使えるごほうびを見せる

## 撮影前にそろえるもの

- 同じペットのサンプル写真を 3〜6 枚
- 日記一覧に数日分のサンプルデータ
- アルバム完成版まで作った月データ
- ごほうびたまごの進行が見える状態

## 補足

- チュートリアル画面は、写真カード風のビジュアルでスクショに使いやすくしてある
- 実際のストア提出では、日記一覧やアルバム画面には実データの写真を入れたスクリーンショットを使うのがおすすめ
