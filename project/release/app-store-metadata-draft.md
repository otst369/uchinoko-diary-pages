## Description

うちの子日記は、ペットとの毎日を写真と短い言葉で残していく思い出アプリです。

1日1回、写真3枚までと一緒に日記を記録できます。あとから日記一覧で見返したり、その月の中から写真を選んで、月ごとのアルバムページとして PDF に残すこともできます。

こんな人におすすめです。

- うちの子との毎日を気軽に残したい
- 写真だけでなく、その日の気持ちも一緒に残したい
- 月ごとに思い出をアルバムのようにまとめたい

主な機能:

- 1日1回、写真つきで日記を記録
- 日記一覧でこれまでの思い出を見返す
- 写真を選んで月ごとのアルバムページを作成
- PDF 保存で思い出を形に残す
