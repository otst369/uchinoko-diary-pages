# アルバムごほうび一覧

現行実装の参照用メモです。ソースは `lib/diary_rewards.dart`。

最終確認: 2026-05-25

## 要点

- 総数は `92個` です。内訳は `連続記録45個` と `書いた日数45個` と `誕生日ごほうび2個`。
- 実際に使っているカテゴリは `背景 / フレーム / タイトル飾り` の3種類です。
- `レイアウト` と `写真配置` は現行報酬には含めていません。
- 初期報酬は `7 / 14 / 180日` と `30 / 60 / 240日`。
- 2年目以降は各トラックで `122日刻みで年3個` ずつ増え、最後は `5475日` です。
