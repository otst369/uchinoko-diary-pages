# プライバシーポリシー

最終更新: 2026-04-15

うちの子日記（以下「本アプリ」）は、ユーザーの思い出を安全に記録・管理するため、必要な範囲で情報を取り扱います。

## 1. 取得する情報

本アプリでは、次の情報を取り扱います。

- メールアドレス
  - メールアドレスログイン、アカウント管理、パスワード再設定のため
- Google アカウント情報
  - Google ログインを利用した場合の認証のため
- ユーザーが入力した日記本文
  - 日記の記録・表示のため
- ユーザーが選択した写真
  - 日記およびアルバム機能で利用するため

## 2. 情報の利用目的

取得した情報は、次の目的で利用します。

- ログイン機能の提供
- 日記データの保存、表示、編集、削除
- アルバムおよび PDF 保存機能の提供
- アカウント管理、パスワード再設定、メールアドレス変更
- 不正利用防止およびサービスの安定運用

## 3. 保存先と利用サービス

本アプリでは、次の外部サービスを利用しています。

- Firebase Authentication
  - ログイン認証のため
- Cloud Firestore
  - 日記本文やアルバム選択情報の保存のため
- Cloud Storage for Firebase
  - 写真データの保存のため
- Google Sign-In
  - Google ログイン機能のため

これらのサービスに関する情報の取り扱いは、各提供元のポリシーもご確認ください。

- Google Privacy Policy  
  https://policies.google.com/privacy
- Firebase Privacy and Security  
  https://firebase.google.com/support/privacy

## 4. 情報の第三者提供

本アプリは、法令に基づく場合を除き、ユーザーの情報を第三者へ販売または提供しません。

ただし、本アプリの機能提供に必要な範囲で、上記の外部サービスに情報が送信されることがあります。

## 5. 情報の管理

本アプリは、ユーザー情報の漏えい、滅失、毀損を防ぐため、合理的な範囲で安全管理に努めます。

## 6. アカウント削除

ユーザーは、本アプリの設定画面からアカウント削除を行うことができます。

アカウント削除を行うと、関連する日記データやアルバムデータも削除対象となります。ただし、バックアップや技術的事情により、完全な削除まで一定期間かかる場合があります。

## 7. 子どもの利用について

本アプリは、一般的な思い出記録アプリとして提供されています。保護者の管理のもとで利用されることを想定しています。

## 8. ポリシーの変更

本ポリシーは、必要に応じて変更されることがあります。重要な変更がある場合は、適切な方法でお知らせします。
