プライバシーポリシー

最終更新: 2026-06-02

うちの子日記（以下「本アプリ」）は、ペットとの思い出を記録し、日記やアルバムとして残せるようにするため、必要な範囲で情報を取り扱います。

1. 取得する情報

  • アカウント情報 : メールアドレス、認証に利用したプロバイダ情報（メールログイン、Google、Apple）を、ログイン、本人確認、メール認証、パスワード再設定、メールアドレス変更のために取り扱います。
  • 日記データ : 日付、本文、写真、タグを、日記の保存、表示、編集、削除、カレンダー表示、アルバム作成のために取り扱います。
  • ペットプロフィール : 名前、プロフィール画像、誕生日、年齢、性格、特技を、プロフィール表示や誕生日演出のために取り扱います。
  • アルバムデータ : 週ごとの写真選択、切り取り位置、月ごとのアルバムスタイル選択情報を、アルバム画面の再表示や編集のために取り扱います。
  • ごほうび情報 : 連続記録や累計記録に応じたごほうびの解放状況を、アルバム装飾機能で使える状態として保持します。
  • 端末内の設定情報 : アプリの表示言語、背景テーマ、通知オンオフと通知時刻、チュートリアル表示状態、広告非表示の端末内状態などを、使い勝手を保つために端末内へ保存します。
  • 通知に関する情報 : 日記リマインドを利用する場合、通知権限と通知時刻設定を利用します。通知そのものは端末上でローカルにスケジュールされます。

2. 情報の利用目的

  • ログイン機能、メール認証、アカウント管理の提供
  • 日記、カレンダー、アルバム、プロフィール機能の提供
  • 日記リマインド通知の設定と配信
  • ごほうび解放状況の表示とアルバム装飾機能の提供
  • 広告表示および広告非表示購入の提供と復元
  • 不正利用防止、障害調査、サポート対応、サービスの安定運用

3. 保存先と利用サービス

  • Firebase Authentication : ログイン認証、メール認証、パスワード再設定のため
  • Cloud Firestore : 日記、プロフィール、アルバム、ごほうび情報の保存のため
  • Cloud Storage for Firebase : 日記写真とプロフィール画像の保存のため
  • Google Sign-In : Google ログイン機能のため
  • Sign in with Apple : Apple ログイン機能のため
  • Google Mobile Ads（AdMob）: バナー広告および保存後広告の表示のため
  • App Store のアプリ内課金 : iPhone / iPad 版の広告削除購入および復元のため

日記リマインドの時刻、表示言語、背景テーマなど一部の設定は、SharedPreferences を利用して端末内に保存されます。

4. 広告と課金について

本アプリは広告表示のために Google Mobile Ads（AdMob）を利用しています。広告配信事業者は、広告配信や不正防止のために端末識別子等を取り扱う場合があります。

広告削除の購入および購入履歴の復元は、Apple の App Store を通じて処理されます。決済情報そのものを本アプリ運営者が保持することはありません。

5. 情報の第三者提供

本アプリは、法令に基づく場合を除き、ユーザーの情報を第三者へ販売しません。ただし、ログイン、保存、広告表示、課金復元など本アプリの機能提供に必要な範囲で、上記の外部サービスへ情報が送信されることがあります。

6. 情報の管理と保存期間

本アプリは、漏えい、滅失、毀損を防ぐため、合理的な範囲で安全管理に努めます。サーバーに保存されたデータは、ユーザーが利用を続けるあいだ保持されます。

端末内の設定情報は、アプリを削除するか、端末側でアプリデータを消去するまで残る場合があります。ユーザー自身が撮影したスクリーンショットや、端末に保存済みの画像・共有済みデータは、本アプリから自動削除できません。

7. アカウント削除

ユーザーは、アプリ内の「設定」→「アカウント」→「アカウントを削除」から退会できます。削除が完了すると、アカウント情報、日記、写真、アルバム、プロフィール、ごほうび情報など、サーバー上の関連データは削除対象になります。

ただし、バックアップや技術的事情により完全な削除まで一定期間かかる場合があります。詳しくはアカウント削除ガイドをご確認ください。

8. 子どもの利用について

本アプリは、ペットとの思い出記録を目的とした一般向けアプリです。未成年の方が利用する場合は、保護者の管理のもとでの利用を想定しています。

9. ポリシーの変更

本ポリシーは、機能追加や法令対応のために見直されることがあります。重要な変更がある場合は、アプリまたは公開ページ上でお知らせします。
